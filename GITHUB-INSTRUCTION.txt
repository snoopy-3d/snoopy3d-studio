ИСПРАВЛЕННАЯ ВЕРСИЯ БЕЗ ПАПОК

1. Распакуйте SNOOPY3D-4-Generators-FIX.zip.
2. Откройте https://github.com/snoopy-3d/snoopy3d-studio → Code → Add file → Upload files.
3. Выделите ВСЕ распакованные файлы (Ctrl+A) и перетащите их в область загрузки GitHub. В этой версии папок нет: index.html, JS, CSS, WASM и три TTF находятся рядом. Не загружайте сам ZIP и не ограничивайтесь одним index.html.
4. Нажмите Commit changes и подтвердите сохранение в main. Существующие одноимённые файлы должны быть заменены новыми.
5. Дождитесь завершения публикации Pages в Actions. Settings → Pages: main, / (root), если это ещё не настроено.
6. Откройте https://snoopy-3d.github.io/snoopy3d-studio/ и нажмите Ctrl+F5.

Должны появиться тёмное оформление, меню и четыре генератора. Установка программ и сборка не нужны. Самостоятельно на GitHub ничего не публиковалось.
