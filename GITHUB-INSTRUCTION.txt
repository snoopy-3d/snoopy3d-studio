SNOOPY3D Studio — четыре генератора

В архиве готовый сайт. Установка программ и сборка не нужны.

1. Скачайте и распакуйте SNOOPY3D-4-Generators.zip.
2. Откройте https://github.com/snoopy-3d/snoopy3d-studio
3. Выберите Code → Add file → Upload files.
4. Перетащите СОДЕРЖИМОЕ распакованной папки: index.html, папки assets, fonts, licenses и документы. Сам ZIP загружать не нужно. Сохраняйте вложенность папок. index.html должен оказаться в корне репозитория.
5. Нажмите Commit changes и подтвердите сохранение в main.
6. Settings → Pages: Source = Deploy from a branch, Branch = main, Folder = / (root), Save. Если эти настройки уже выбраны, менять их не нужно.
7. Дождитесь успешной публикации в Actions / Pages и откройте https://snoopy-3d.github.io/snoopy3d-studio/
8. Обновите страницу Ctrl+F5. В «Генераторы 3D» должны быть только: Коробки, Вазы и кашпо, Абажуры, SKÅDIS.

Как пользоваться
Выберите генератор, меняйте параметры, вращайте модель мышью или пальцем. Когда проверка сетки завершена, скачайте STL или 3MF. Откройте файл в Bambu Studio в миллиметрах и выберите принтер/материал. Несколько деталей разложены для печати; крышка, поддон или диффузор могут находиться рядом с основной деталью.

Готовые образы автоматически подбирают достаточную стенку. При ручных параметрах недопустимые значения показывают сообщение и блокируют скачивание. Сохранённые параметры доступны в «Мои модели»; удалённые типы генераторов там не показываются.

Если сайт показывает старую версию: убедитесь, что новый index.html лежит в корне, публикация завершилась успешно, затем нажмите Ctrl+F5 или откройте сайт в приватном окне. Если страница без оформления — проверьте, что папка assets загружена целиком.

Для работы сайта нужен HTTP/HTTPS. Двойной щелчок по index.html на компьютере не является проверкой: браузер может блокировать WASM и шрифты через file://.
