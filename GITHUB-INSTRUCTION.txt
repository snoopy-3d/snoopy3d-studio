SNOOPY3D STUDIO — ОБНОВЛЕНИЕ ГЛАВНОЙ СТРАНИЦЫ

1. Распакуйте SNOOPY3D-Homepage.zip.
2. Откройте https://github.com/snoopy-3d/snoopy3d-studio → Add file → Upload files.
3. Перетащите ВСЕ распакованные файлы в область загрузки. Загрузите содержимое архива, а не сам ZIP. Все файлы находятся рядом, вложенных папок нет.
4. Нажмите Commit changes, подтвердите сохранение в main. Разрешите замену одноимённых файлов, особенно index.html. Старые файлы с другими именами можно оставить.
5. Дождитесь успешного завершения GitHub Pages в Actions. Settings → Pages: main, / (root).
6. Откройте https://snoopy-3d.github.io/snoopy3d-studio/?v=homepage-20261029#home
Если видите старую страницу — Ctrl+F5.

В результате: новая главная, неоновый логотип, услуги, пять работ из Telegram, контакты и свечение курсора. Четыре генератора, калькуляторы и сохранённые модели доступны в меню.

Фото уже включены в архив, посетителям не нужно подключаться к Telegram для их загрузки. Галерея статическая: новые публикации автоматически не добавляются. Ссылки ведут на оригинальные посты.

Свечение работает с мышью на свободном фоне всех страниц; выключено на телефонах и при системной настройке уменьшения анимации. Геометрические ограничения описаны в LIMITATIONS.md.

Это готовая статическая сборка, устанавливать программы и собирать проект не нужно. Обновление не опубликовано автоматически: загрузите файлы по шагам выше.
