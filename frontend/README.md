# SNOOPY3D frontend

Исходники яркого редизайна и 11 инструментов находятся в `source/`. Готовый сайт публикуется GitHub Pages из корня репозитория.

Для разработки нужен Node.js 22 или новее. В этой папке выполните `npm install`, затем `npm test` и `npm run build`. Сборщик обновляет статические файлы в корне, сохраняет остальные файлы и использует только публичные медиа из корня. Сервер заказов запускается и тестируется прежними командами из корня репозитория.

Ключ локальных проектов `snoopy3d_studio_v1` и ключ расчётов `snoopy_calc` сохранены. Геометрия превью и экспорта общая; перед экспортом проверяются замкнутость, нормали и вырожденные грани. Параметры STL рассчитаны в миллиметрах, 3MF явно хранит единицу mm.

Баннер и четыре иллюстрации каталога созданы ImageGen. Остальные карточки — изображения настоящих параметрических моделей. В галерее используются только фотографии пользователя. Файлы `.public/`, `.dist/` и `node_modules/` не являются исходниками и не должны коммититься.
